A quick start

From your terminal to your next commit.

Install it above, then you're ready to go.

  1. 01

    Open your project

    Go to the folder you want to work on and start jig.

    cd your-project
jig
  2. 02

    Tell jig what you need

    Type a task in plain language and press Enter. Jig can read files, make changes, and run commands.

    “Explain how this project works.”
    “Fix the failing tests.”
    “Add a health check endpoint.”
  3. 03

    Review and keep going

    Watch the work in your terminal, review the changes, and ask a follow-up. Press Esc to stop a task.

A few useful commands

Type these inside jig.

/models
Choose the model you want to use.
/providers
Connect your own provider with an API key.
/clear
Start a fresh conversation.
/exit
Close jig when you're done.
